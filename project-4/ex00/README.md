# Personal Portfolio

## About
This is a responsive personal portfolio created using HTML5, CSS3, and JavaScript.

## Features
- Personal introduction and profile photo
- Skills grid
- Four project cards
- Hobbies section
- Contact form with basic validation
- Interactive dark and light theme switcher
- Responsive layout using Flexbox, CSS Grid, and media queries

## Technologies
- HTML5
- CSS3
- JavaScript ES6+

## Run the project
Open `index.html` in a web browser.

## JavaScript Event Lifecycle
1. The user clicks the theme button.
2. The browser fires a click event.
3. JavaScript executes the registered callback function.
4. `classList.toggle()` adds or removes the `dark-theme` class from the body.
5. CSS variables update the page background, text, and surface colors.

## Contact Form
The form uses native HTML validation and JavaScript event handling. It does not currently send messages to a server.
